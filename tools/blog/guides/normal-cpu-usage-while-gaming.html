Across six games since 18 October, my Ryzen 7 5700X3D averaged between 13% and 47% busy. In about 88 hours of play it never reached 90% in a single minute. The highest minute was 87%, in Phantom Blade Zero. That's what normal CPU usage while gaming looks like on a current 8-core processor, and it isn't like the GPU, which in the same game sat near 100% most of the time.

How RigSight caught it

RigSight records the CPU's usage every minute, for the whole PC and for each app, next to the frame rate and the game in front. That's how I can see not only how busy the CPU was, but whether the game or something else made it busy.

When stutters bunch up, five or more within 15 minutes, and you open the play frame by frame, RigSight checks what else was going on. If another app used 20% of the CPU or more there, and at least twice what it used in the rest of the play, it names that app as busy in the background. On the Games page, a game whose GPU rarely or never reached full load gets the line that something else sets the pace, most likely the CPU. RigSight is free and open source.

Normal CPU usage while gaming

Here's what each game did on my 8-core, 16-thread 5700X3D.

  • Phantom Blade Zero averaged 47%, with its busiest minute at 87%.
  • REMATCH averaged 45%.
  • Dota 2 averaged 34%.
  • Crimson Desert averaged 28%, with the GPU at full load nearly the whole time.
  • Risk of Rain 2 averaged 24%.
  • Slay the Spire 2 averaged 13%.

With nothing much running, the same CPU sits around 7%. A CPU with fewer cores reads higher in the same game, because the same work is spread over less. A 4-core CPU at 70 or 80% in a modern game isn't unusual.

Is 100% CPU usage normal while gaming?

Not usually, and this is where the CPU and GPU differ. A GPU at 99% is doing its job. Most games can't spread their work evenly over every core, so a CPU at 100% for minutes at a time usually means something extra is going on.

  • A background app is busy, like a browser, a launcher downloading or installing, an antivirus scan or cloud sync.
  • The CPU has few cores for the game, so the game alone fills it.
  • The game is building shaders, often the first time you play after a game or driver update. That passes.
  • Something is stuck, like a process using a full core in a loop.

A CPU at 100% leaves nothing for the moments a game needs a little more, so it often comes with stutters.

Low CPU usage can still hold the frame rate back

Total CPU usage is the average of every core. Many games do most of their work on one main thread. If that thread fills one core, the game waits for it, even while the total reads 25%. My Risk of Rain 2 sessions are a good example to look at, with the CPU 24% busy and the GPU only 55% busy at about 151 FPS. Something other than the GPU set that pace, the CPU or a frame limit.

To check, open Task Manager's Performance tab, click CPU, right-click the graph and choose Change graph to > Logical processors. One or two cores near the top while the rest idle is what a main thread looks like.

How to fix high CPU usage while gaming

  1. Open Task Manager with Ctrl + Shift + Esc while the game runs, sort Processes by CPU, and close anything busy that isn't the game.
  2. Pause launcher downloads, cloud sync and browser video while you play.
  3. Give it a second session after a game or driver update, in case it was building shaders.
  4. Use the Balanced power plan, or Best performance under Settings > System > Power & battery, and play laptops on the charger.
  5. Update the game, the chipset driver from AMD or Intel, and Windows.
  6. Lower the settings that lean on the CPU, such as crowd or unit density, view distance, physics and shadows' draw distance.
  7. Check the CPU's temperature. A CPU that gets too hot slows itself. Normal CPU temperature while gaming has the numbers.

Your next step is to watch CPU and GPU usage together in a game that feels slow. A GPU near 100% means the CPU is fine. A GPU well below that, with no frame limit, means the CPU or the game sets the pace, so start with the list above. Normal GPU usage while gaming covers the GPU side.
