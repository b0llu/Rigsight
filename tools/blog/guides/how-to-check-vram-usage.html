My GPU has 12 GB of memory. Playing Phantom Blade Zero, the game itself used up to 7.2 GB of it, usually about 6. Playing Risk of Rain 2 on the same PC, it used about 2 GB. Same card, about three times the difference. That's why a list of how much VRAM games use only goes so far. Here's how to check VRAM usage for your own games on Windows 11, and how to tell when it's really too high.

How RigSight caught it

RigSight records the GPU's memory every minute, both the whole card and the game in front. On the Games page, each game shows its graphics memory as "up to" its highest of the card's total, for the game's own use when Windows reports it, or for the whole card and all apps when it doesn't. That's where my two numbers came from.

RigSight doesn't treat nearly full as a problem by itself, because many games fill the card on purpose. It only speaks up when memory ties in with something that went wrong. When a game crashes with the card's memory nearly full, at least 90%, and at least 1 GB and 15% above what that game usually uses on your PC, the opened crash says so. It's careful about it, because running out of memory can crash a game, but a game that simply loaded more looks the same. And when stutters bunch up while the card's memory is 95% full or more, the play's frame-by-frame view names that as what was going on. You can also put GPU memory used in the overlay, a widget or the taskbar. RigSight is free and open source.

VRAM usage in games, and when it's too high

VRAM is the GPU's own memory. Games keep textures, models and the frames being drawn there, because the card can reach it much faster than the PC's main memory. Higher texture settings, higher resolutions and ray tracing all take more of it.

When it runs out, the card can have to fetch data from the PC's main memory instead, which is far slower. That shows as stutters when you turn into a new area, textures that appear blurry and sharpen late, and in bad cases crashes. Nearly full without any of that is fine. A game that keeps 10 GB of a 12 GB card filled may just be using the room it has.

How to check VRAM usage on Windows 11

  1. Press Ctrl + Shift + Esc to open Task Manager.
  2. Open Performance and click your GPU, usually GPU 0. Dedicated GPU memory is the card's own memory in use, out of its total.
  3. To see one game's use, open Details, right-click a column heading, choose Select columns and tick Dedicated GPU memory. Sort by it while the game runs.

Shared GPU memory is main memory the card can borrow. On a gaming card with its own memory, a lot of it in use can be a sign the card ran short.

To check VRAM usage while gaming, you need it on screen or recorded, because tabbing out changes what the game is doing. An overlay that shows GPU memory, or a tool that records it, works better than Task Manager for that.

How to fix VRAM usage that's too high

  1. Lower Texture quality one step first. It usually saves the most memory for the least visible change.
  2. Turn down ray tracing, or turn it off. It needs extra memory on top of everything else.
  3. Lower the resolution, or use your card's upscaling, such as DLSS, FSR or XeSS, which draws at a lower resolution and scales it up.
  4. Close other apps that use the GPU, like browsers with video or capture tools, before you play.
  5. Update the game and the graphics driver, since games sometimes fix memory use in patches.

Your next step is to check your heaviest game's VRAM usage against your card's total. If it sits near the top and the game stutters, lower textures first. If it sits near the top and plays fine, leave it alone. For stutters with plenty of memory free, see games stuttering on PC.
