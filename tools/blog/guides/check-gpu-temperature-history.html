Your game stuttered an hour ago, or the PC shut off last night, and you want to know how hot the graphics card got. So you look for a way to check GPU temperature history in Windows, and find there isn't one. Windows shows the temperature right now and forgets it. Here is how to start keeping a GPU and CPU temperature history, and how to read it.

Does Windows keep a temperature history?

No. Windows records crashes, updates and errors in its logs, but not temperatures. Task Manager can show the temperature of a dedicated graphics card, and that's the only temperature Windows itself shows. It has no CPU temperature reading at all, and it saves neither.

That means you can only look back at times when some app was already recording. If nothing was running last night, last night's temperatures are gone. The useful habit is to set up recording before you need it.

How to check GPU temps right now

For a quick look at the current reading in Windows 10 version 2004 or later, or Windows 11:

  1. Press Ctrl + Shift + Esc to open Task Manager.
  2. Open the Performance tab.
  3. Click your graphics card, usually GPU 0 or GPU 1.
  4. Read GPU Temperature under the graphs.

Integrated graphics built into the CPU don't show a temperature here. The graphs on this tab cover only the last minute, and they aren't temperature graphs.

How to check GPU temperature history with HWiNFO

HWiNFO is a free sensor app that reads nearly every chip in a PC, CPU included, and can write the readings to a CSV file you open in a spreadsheet.

  1. Download HWiNFO from its official site and run it.
  2. Tick Sensors-only and click Start.
  3. At the bottom of the sensors window, click the logging button, the icon with a green plus.
  4. Pick a folder and a file name for the CSV log.
  5. Play as you normally would.
  6. Click the same button, now a red cross, to stop.

Open the CSV in Excel or Google Sheets and find the column for GPU Temperature, or the CPU column for your chip. Sort it or make a quick line chart. Some guides suggest lowering HWiNFO's polling interval for finer detail, but the default is fine for temperatures.

The catch is that it only records while HWiNFO is open and logging. You have to remember to start it, and a log left running for days grows into a very large file.

Other ways to log GPU temperature

  • GPU-Z has a Log to file box on its Sensors tab. It records the graphics card only.
  • MSI Afterburner draws a monitoring graph of the last few minutes, and its Settings > Monitoring tab has a Log history to file box that saves it. With RivaTuner Statistics Server it can also show the temperature on screen while you play.

All of them have the same limit as HWiNFO: they only know about the time they were running and logging.

How to check GPU temps while you play

Tabbing out to Task Manager mid game changes what you're measuring, because the card relaxes as soon as the game is in the background. An overlay shows the reading while the game keeps running. The NVIDIA app and AMD Software each have a performance overlay that can include GPU temperature. MSI Afterburner can show it too, drawn in the game by RivaTuner Statistics Server, which installs alongside it.

An overlay is good for watching, but it's still only now. Glance at it once the game has run for 10 minutes, then let a log or a background recorder keep the rest.

What to look for in a temperature history

A pile of numbers is only useful if you know what to ask of it.

  • The highest reading in a session, and when it happened. Compare it with your card's maximum: NVIDIA lists 85 to 93°C for its recent GeForce cards depending on the model, for example 90°C for the RTX 4070 family.
  • Where the temperature levels off. A short spike to the high 80s is less worrying than an hour spent there.
  • The same game over weeks. If one game settles 6 or 8 degrees hotter than it did last month, at the same settings, dust or paste may be building up.
  • The temperature at rest. A PC idling warmer than it used to, with the room the same, points the same way.

For what counts as normal, see normal GPU temperature while gaming and normal CPU temperature while gaming. If the history shows a real problem, PC overheating while gaming has the fixes.

Keeping a PC temperature history all day with RigSight

RigSight is a free, open-source PC monitor for Windows that does the logging for you. It records CPU, GPU, GPU hot spot and GPU memory temperatures all day, with no log to start, and keeps the history for as long as you choose. Motherboard and drive temperatures show live on the same page. CPU temperature, motherboard and drive readings need RigSight to run with admin rights.

The Temperatures page has a history graph with one range menu, from the last 5 minutes to the last 12 months, plus a Custom range. Week, Month and Year are the last 7 days, 30 days and 12 months. Each minute can be drawn as its average, highest or lowest, so a short spike shows up instead of hiding in an average. Drag across any stretch to zoom in. Time when nothing was recorded is marked with a strip along the bottom of the graph, and hovering it gives the reason when Windows knows it, such as the PC being off or asleep, so a gap never looks like a cool PC. The same page shows the warmest hours of the past week and the CPU's and GPU's resting temperature over the last 30 days.

Reports covers any day, week, month, year or custom range. For a single day, its minute by minute graph lines temperatures up with the app in front. For any period, Peaks lists the highest CPU, GPU and GPU hot spot readings with the app that was running. If you want the raw numbers, the Export button on the page saves what it shows, and the Export in Settings can save temperatures as CSV files for a spreadsheet.

Whichever tool you pick, start recording today. The next time a game stutters or the PC shuts off, you'll have the hour before it to look at instead of a blank.
