Your internet slows down in the evening, your data cap is nearly used up, or the router lights flicker while you are not doing anything. You want to know which app is using your internet. Windows can show you, in three places, and each answers a slightly different question.

Which app is using the internet right now

Task Manager

  1. Press Ctrl + Shift + Esc to open Task Manager.
  2. Pick Processes.
  3. Click the Network column header to put the busiest apps on top.

The Network column shows each app's speed right now, in Mbps. It updates every second or so, which is good for catching something mid download, and useless for anything that happened an hour ago.

Resource Monitor

  1. Press Start, type resmon and open Resource Monitor.
  2. Pick the Network tab.
  3. Open Processes with Network Activity and click Total (B/sec) to sort by it.

Resource Monitor lists every process separately, including Windows services that Task Manager folds together. The Network Activity section below it shows which addresses each process talks to, and TCP Connections lists every open connection. If a process name means nothing to you, right-click it and choose Search Online.

Which apps used the most data in the last 30 days

  1. Open Settings > Network & internet > Advanced network settings > Data usage. On some versions of Windows, Data usage sits straight under Network & internet.
  2. Pick the network at the top, such as Wi-Fi or Ethernet. Each is counted separately.
  3. Read the list of apps, biggest first.

This is the best built-in answer to which app used the most. It has limits, though. It only covers the last 30 days. It shows totals with no times, so you can't tell whether that 40 GB was last night or three weeks ago. It also can't tell you how much an app used while it sat in the background.

Task Manager's App history tab also shows network use per app since a date at the top. If it lists only Microsoft Store apps, turn on Show history for all processes in Task Manager's Settings.

What usually uses internet in the background

When nobody is at the PC and data still moves, it is nearly always one of these:

  • Game launchers such as Steam, Epic, Battle.net and the EA app, downloading game updates. A single update can be tens of GB.
  • Windows Update, plus Delivery Optimization, which can also upload updates you already have to other PCs.
  • Cloud sync and backup, such as OneDrive, Google Drive, Dropbox or a phone photo backup. These upload as much as they download.
  • Browsers and chat apps left open, with streams, videos or calls running in a tab you forgot.

How to stop background data usage in Windows 11

Set the connection as metered

Open Settings > Network & internet, pick Wi-Fi or Ethernet, open your network's properties and turn on Metered connection. Windows then holds back most update downloads, and some apps, OneDrive for example, pause syncing. Some apps don't follow the setting at all, so check the big ones yourself.

Set a data limit

In the Data usage page, press Enter limit to set a monthly or one-off limit for that network. Windows warns you as you get close to it.

Stop uploading updates to other PCs

Open Settings > Windows Update > Advanced options > Delivery Optimization. Turn off Allow downloads from other devices, or limit it to devices on your local network. The Activity monitor on the same page shows how much your PC uploaded this month.

Stop apps running in the background

For apps from the Microsoft Store, open Settings > Apps > Installed apps, press the three dots beside an app, choose Advanced options and set Let this app run in the background to Never. For other apps, turn them off in Task Manager's Startup apps so they don't start with Windows, and set game launchers and sync apps to update or sync only when you want. Steam, for example, can be told to update games only within set hours in its Downloads settings.

See which app used your internet, and when, with RigSight

The Windows tools either show this second or a 30 day total. RigSight, a free and open source PC monitor, records each app's internet use all day and keeps it, so you can look at any day, week, month or year after it happened.

The Network page shows how much each app downloaded and uploaded, with a chart you can colour by app or by in front and background. Background means what an app moved while it wasn't the window in front, or while nobody was at the PC, and RigSight counts while you were away apart. Click a bar to see which apps used the internet in that hour or day. Sort the apps by total, download, upload or background, and see your biggest days with the apps behind them. A line points it out when an app uploads far more than it usually does, which is how a runaway backup or sync usually shows.

The Apps page can sort every app by internet use, and each app's card shows what it downloaded and uploaded, and how much of that was in the background. Home shows how much has been downloaded today. The Connection card also shows when your internet dropped.

Per-app internet use needs RigSight to run with admin rights. On a standard Windows account, the Network page shows the whole PC's use instead, with what moved while you were away.

Start with Resource Monitor's Network tab if something is using the internet right now, and the Data usage page for the last month. If the answer is a launcher or Windows Update, the settings above will tame it. If it is an app you don't recognise, search its name before you block or remove it.
