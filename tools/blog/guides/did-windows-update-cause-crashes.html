Your PC was fine, Windows installed an update, and now games crash or the frame rate is lower than it was. Did a Windows update cause the crashes? Sometimes. More often the update just happened the same week as something else. The way to know is to line up the dates, and Windows already keeps the records you need.

Step 1. See what was installed and when

  1. Open Settings > Windows Update > Update history.
  2. Look at the dates under Quality updates, Driver updates and Feature updates.
  3. Write down any update installed in the day or two before the trouble started.

Pay most attention to Driver updates. Windows Update can install a graphics, audio or chipset driver on its own, and a new graphics driver is a likely suspect for game crashes. If a graphics driver is on the list, start with games crashing after a graphics driver update.

A feature update, the big yearly version change, also deserves a look. It replaces much more of Windows and can bring back default settings.

Step 2. Line the crashes up in Reliability Monitor

Reliability Monitor is the easiest place in Windows to see crashes and updates on the same chart.

  1. Search Start for reliability and open View reliability history.
  2. Switch the view to Days. Each column is one day.
  3. Red marks are critical events such as app crashes and Windows shutting down unexpectedly. Blue marks are information, including each Windows update that installed.
  4. Click a day to see the list of events at the bottom.

What you are looking for is a clear before and after. If the red marks start the day an update installed and were rare before, the update is a real suspect. If the red marks were already there the week before, the update didn't start them. If the crashes are blue screens or the PC restarting by itself, the codes in those events matter more than the update, and how to find out why your PC crashed covers reading them.

Step 3. Check whether Microsoft already knows

Microsoft keeps a list of known problems for each Windows version on its Windows release health pages. Search the page for the KB number from your Update history. Game problems have shown up there before. In 2022, for example, Microsoft listed lower than expected performance in some games on Windows 11 version 22H2 and fixed it in a later update. If your problem is listed, the page usually says whether a fix or a workaround exists, and you may only need to wait or install the next update.

Step 4. Uninstall the update to test it

If the dates line up and nothing else changed, remove the update and see whether the problem goes away. It's not something to do casually, because most updates include security fixes, and some can't be uninstalled.

  1. Open Settings > Windows Update > Update history.
  2. Scroll down to Related settings and pick Uninstall updates.
  3. Find the update by its KB number and press Uninstall.
  4. Restart the PC.

Then go back to Settings > Windows Update and pick Pause updates, or Windows may install the same update again. Play as you normally would for a few days. If the crashes stop, you found it. Resume updates once Microsoft's release health page shows a fix.

After a feature update, the way back is different. Windows keeps the previous version for a limited time, in most cases 10 days, and Settings > System > Recovery > Go back returns to it while that option is still there. Your files stay, but apps and drivers installed since the upgrade are removed.

If the problem is an FPS drop in games after a Windows update

An FPS drop is harder to prove than a crash, because frame rate changes with the scene, the game's own patches and even the room's temperature. Compare like for like, with the same game, the same settings and the same spot before and after. Then check what an update can change.

  • The graphics driver. If Windows Update installed its own graphics driver, it can be older than the one you had. Check the version in Device Manager > Display adapters and install the current driver from NVIDIA, AMD or Intel.
  • Memory integrity. Microsoft says memory integrity and Virtual Machine Platform can cost performance in some games on some PCs, and that gamers may turn them off while playing. Memory integrity is under Windows Security > Device security > Core isolation details. Turning it off makes the PC less protected, so turn it back on when you're done.
  • Game Mode and graphics settings. Check that Settings > Gaming > Game Mode is still on, and look at Settings > System > Display > Graphics for the GPU each game is set to use.
  • The power plan. If the plan switched to Balanced or Power saver, the CPU can clock down. See why your power plan keeps changing.

How RigSight answers "what changed?" for you

All of the steps above depend on you working out the dates after the fact. RigSight, a free and open source PC monitor, writes them down as they happen.

The Timeline lists every Windows update by its KB number with the time it installed, next to driver installs, Windows version upgrades and setting changes such as Game Mode, memory integrity and hardware-accelerated GPU scheduling being turned on or off. Pick Windows in the Timeline's filter to see only the updates.

For a Windows update, a graphics driver, a BIOS update or a power plan change, RigSight also checks whether the PC got better or worse after it. It compares the same game at the same load before and since, with the warmth of the room taken out, and counts the problems that kind of change can cause, such as graphics driver resets after a graphics driver, against the hours the PC was used. When something moved, the Timeline says so under the change, and the Before and after filter lists only those. A change that made no difference it could measure gets no line at all, so a quiet Timeline is a real answer.

When a game crashed, the opened crash on the Crashes page lists the drivers and Windows updates from the seven days before it. For frame rates, each game's page on Games shows every play with its average FPS and 1% low, and the list of plays shows the Windows updates and drivers that came in between. Frame rate readings need RivaTuner Statistics Server running.

Start with Update history and Reliability Monitor today. If the dates line up, uninstall the update and pause updates for a week. If they don't, the update was a coincidence, and the cause is somewhere else in that week.
