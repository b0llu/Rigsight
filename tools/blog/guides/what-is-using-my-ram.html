Your PC feels slow, you open Task Manager and memory says 80 percent. Maybe you only have a browser open, maybe nothing at all. Here is how to find out what is using your RAM on Windows 11, which of those numbers are normal, and what to do when one app keeps taking more.

Find the biggest memory users in Task Manager

  1. Press Ctrl + Shift + Esc to open Task Manager.
  2. Pick Processes on the left.
  3. Click the Memory column header. The apps holding the most memory move to the top.
  4. Click the arrow next to an app to see the separate processes inside it.

Browsers, Discord, Steam and many other apps run as several processes, so one name can hide twenty of them. The list is split into apps, background processes and Windows processes. Lines called Service Host are parts of Windows, grouped by the service they run.

If one app is clearly holding the most, you have your answer. Close it, or close the tabs or projects inside it you don't need. If nothing in the list looks big but the total is still high, read on.

Why the total is higher than the list adds up to

The Processes list only counts memory that apps hold. Windows also uses RAM for itself, for drivers and as a cache. To see all of it, open Performance in Task Manager and pick Memory. The figures under the graph mean the following.

  • In use is memory that apps and Windows hold right now. The number next to it in brackets is the compressed part.
  • Compressed memory is memory apps aren't touching at the moment, squeezed by Windows so more fits in RAM. It is faster than writing it out to the drive, and it is normal to see a few hundred MB or more.
  • Cached is files and programs Windows keeps in RAM in case you open them again. Windows hands this memory to any app that asks for it, so a big cache is a good thing.
  • Available is what apps can still get, which is free memory plus the cache that can be given back.
  • Committed is memory promised to apps, counted against your RAM and the page file together. When it gets close to the limit, Windows warns that the PC is low on memory.
  • Non-paged pool is memory the Windows kernel and drivers use. It should stay fairly steady.
  • Hardware reserved is set aside before Windows starts, for example for integrated graphics.

The figure to watch is Available. Plenty available means you have room, even if In use looks high.

Get a clearer split with Resource Monitor

  1. Press Start, type resmon and open Resource Monitor.
  2. Pick the Memory tab.
  3. Click the Private (KB) column to sort by it.

Private memory belongs to that process alone, so it is the best single figure for which app is holding your RAM. The bar at the bottom splits all memory into Hardware Reserved, In Use, Modified, Standby and Free. Standby is the same cache Task Manager calls Cached. Modified is memory waiting to be written to the drive before it can be reused, and it is usually small.

High memory usage on Windows 11 with nothing running

When you haven't opened anything and memory is still high, it is usually one of these.

Apps that start with Windows

Game launchers, chat apps, RGB and peripheral software, cloud sync and updaters all load at sign-in and sit in the tray. Open Task Manager, pick Startup apps, right-click anything you don't need right away and choose Disable. It still works when you open it yourself.

A browser that never closed

Chrome and Edge can keep running in the background after you close the last window, so extensions and apps can keep working. Turn that off in the browser's settings if you don't want it. In Chrome it is under Settings > System, in Edge under Settings > System and performance.

The cache after a game

After a big game, Cached can stay high for a while. That is Windows keeping files ready, not memory being lost. You don't need a RAM cleaner app to clear it. Those tools empty the cache, and Windows fills it again.

Work after an update

After a large Windows update, Windows often reindexes files and does other background work for a while. Restart and give it a few hours before you chase it.

A memory leak

If one app grows hour after hour while you do nothing more in it, it is leaking. Restart that app to get the memory back, then update it. If it keeps happening, the app's own support page or forum usually knows about it.

High memory usage not showing in Task Manager

If Performance > Memory says most of your RAM is in use but the Processes list adds up to far less, look at the Non-paged pool figure. If it keeps climbing over hours and reaches several GB, a driver is probably leaking memory. Drivers you installed or updated recently are the first suspects. Update or reinstall them, and restart.

To see exactly where memory has gone, Microsoft's free Sysinternals tool RAMMap splits all of it by use, including driver memory, the cache and each process. It needs to run as administrator.

Browser tabs and Chrome's high memory usage

Each tab and extension in Chrome or Edge is its own process, which is why a browser so often tops the list. Two settings help.

  • In Chrome, open Settings > Performance and turn on Memory Saver. Tabs you haven't used for a while are put to rest and reload when you go back to them.
  • In Edge, open Settings > System and performance and turn on sleeping tabs, which does the same.

To find the one heavy tab, press Shift + Esc inside Chrome or Edge. The browser's own task manager lists every tab and extension with its memory.

When high memory use is a real problem

High In use on its own is fine. It is a problem when Available is close to zero, the drive light stays busy while apps stutter, or Windows tells you the PC is low on memory. Then the fix is to run less at once, find the leaking app, or add RAM. Windows 11 needs at least 4 GB to run, and games and browsers with many tabs need a lot more than that. Leave the page file on and let Windows manage its size. Without it, apps can close without warning when memory runs out.

See your memory with a history in RigSight

Task Manager shows what is using memory right now. It doesn't tell you whether an app always uses that much, or only started today. RigSight, a free and open source PC monitor, keeps a record of each app's memory all day, so it can.

The Memory page shows how full your RAM is, with today's lowest and highest, and splits it into apps, compressed and free. Below that, every running app is listed with what it holds now beside its usual, which is its average over the days before today. An app well above its usual is marked, such as "Twice its usual", and a card points it out. If it has grown every hour for a few hours, the card says since when, which is how a leak usually looks. When nothing is above its usual, the page shows the apps holding the most instead. Today's biggest memory users lists each app's peak and average, and a card shows when memory was fullest today and which apps held the most around then.

On the Processes page, open a browser or another app made of many processes, and RigSight splits its memory into its tabs, its extensions and the app itself, with its recorded history beside it. You can end an app there too, with a warning before you end a part of Windows.

Start with Task Manager's Memory column and the Available figure. If nothing stands out, check Startup apps and your browser's settings. If something keeps growing, restart it and update it, and if the Non-paged pool is the one growing, update your drivers next.
