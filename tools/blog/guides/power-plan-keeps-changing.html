You set High performance, and a day later Windows is back on Balanced. Or it flips while you play and you only notice because the game feels different. If your power plan keeps changing to Balanced in Windows 11, Windows itself is rarely the one doing it. Some other program on the PC is switching it, and the job is to find out which.

Check which power plan is active right now

Windows has two power settings that look alike, so start by checking the right one.

  1. Press Win + R, type powercfg.cpl and press Enter. This opens Power Options, where the selected plan is the power plan.
  2. Or open Command Prompt and type powercfg /getactivescheme. It prints the active plan's name and its ID.
  3. Type powercfg /list to see every plan on the PC. The one with a star next to it is active.

Keep that list open. The long IDs are how you will recognise the plans in Event Viewer later. The ones every PC has are Balanced, which starts 381b4222, High performance, which starts 8c5e7fda, and Power saver, which starts a1841308.

Power plan and power mode are not the same thing

Windows 11 also has Settings > System > Power & battery > Power mode, with Best power efficiency, Balanced and Best performance. That is the power mode, and it sits on top of the power plan.

Microsoft's documentation for PC makers says the power mode only appears when the Balanced plan, or a plan based on it, is selected. It also says that once a PC is on Balanced, there is no way back to High performance from the settings pages, only with the powercfg command. That explains a lot of what people see:

  • If your Power Options window only lists Balanced, that is how many Windows 11 PCs ship. It isn't a fault.
  • Choosing a power mode in Settings means using Balanced. If you pick High performance in Power Options, the power mode setting disappears.
  • On a laptop, the power mode is set separately for plugged in and on battery, so unplugging can look like a change of plan.

For most people, the simple fix is to stay on Balanced and set Power mode to Best performance while plugged in. That's the setup Windows 11 is built around. If you really want High performance, carry on below.

What switches the power plan behind your back

  • Laptop and motherboard maker tools. ASUS Armoury Crate, Lenovo Vantage, MSI Center, HP OMEN Gaming Hub, Dell and Alienware tools and others have their own performance or fan modes, and some of them work by setting the Windows power plan or power mode. Switching modes in the tool, or the tool starting with Windows, can change your plan.
  • Game boosters and optimizers. These often set a fast plan when a game starts and put the old one back when it closes. If one crashes or is closed halfway, the plan can stay wrong.
  • Chipset driver installs. Installing or updating a chipset driver can add the maker's own plan and select it. Older AMD chipset drivers added plans called AMD Ryzen Balanced and AMD Ryzen High Performance, and later versions stopped adding them for some Ryzen models.
  • Battery tools on laptops can pick Power saver when you unplug.
  • A work or school PC can have the plan set by its administrator through Group Policy, and it will change back however often you set it.

Find the program that changed it

Windows often records which program set the power plan. Here's how to look.

  1. Open Event Viewer and go to Windows Logs > System.
  2. Press Filter Current Log on the right.
  3. Under Event sources, pick UserModePowerService, and type 12 in the event ID box. Press OK.
  4. Open the entries near the time the plan changed. Each one names a program with its full path and says it set the plan from one ID to another.

Many of these entries are harmless, where the two IDs are the same and nothing really changed. Look for an entry where the two IDs differ and the second one matches the plan you didn't want. The program it names is your culprit. If it is a maker's tool, open it and look for a performance mode or power setting, and either pick the plan you want there or stop it from managing power. If you don't use the tool, you can stop it starting with Windows in Task Manager > Startup apps, and see whether the plan stays put.

If the log has nothing useful, do it by elimination. Turn off one startup program at a time, restart, and see whether the plan still changes.

Set the plan back

Once the program behind it is dealt with, set the plan you want in Power Options. If High performance isn't listed, the powercfg command can bring it back. Open Command Prompt as administrator and type:

powercfg /duplicatescheme 8c5e7fda-e8bf-4a96-9a85-a6e23a8c635c

That adds a copy of Windows' High performance plan, which then shows in Power Options and can be selected there. To go back to Balanced at any time, type powercfg /setactive SCHEME_BALANCED. None of this needs the registry, and it is easy to undo.

Before you fight hard for High performance, know what it does. It mainly stops the CPU from slowing down and sleeping when there is little to do. On modern desktop CPUs the difference in games is often small, and it uses more power at idle. Microsoft suggests that makers of gaming PCs consider giving the Balanced plan the same settings as High performance.

How RigSight catches every switch

The frustrating part of this problem is that the change is silent. You notice it hours later and have no idea when it happened. RigSight is a free, open source PC monitor that checks the active power plan every minute while it runs and writes down every change.

Each switch is its own line on the Timeline, such as "Power plan changed to Balanced", with what it was before and the time RigSight noticed it. Pick Settings in the Timeline's filter to see only setting changes. The "This PC now" panel shows the plan you are on and since what date.

RigSight doesn't know which program made the switch. What it gives you is the time, and that is what makes the Event Viewer search above quick. Look at the UserModePowerService entries from that minute. The same day's Timeline also shows whether an app or a driver was installed or updated just before, which often answers it on its own.

A power plan change also counts as a big change on the Timeline. If a game ran clearly hotter or cooler after it, the Timeline says so under the change, and because a plan changes power use by design, it shows the GPU's power next to the temperature.

Start by checking Event Viewer for the last time the plan changed. If it names a maker's tool, change the setting there first. Most of the time the plan then stays where you put it.
